## Bidirectional peer-mesh delegation and serialized builds

Parallel swarm workers and subagents connect as a **2-way all-to-all general graph** (`PeerMeshGraph` in [`cpp/include/omnia/graph/peer_mesh.hpp`](cpp/include/omnia/graph/peer_mesh.hpp): `A <-> B` duplex links, `sibling <-> sibling`, `author <-> verifier`, `child <-> parent` with cursor-based `read_since(seq)` wakeup and bounded `max_hops` / `epoch` cycle guards). Prefer deterministic `Graphify` forward/reverse symbol and doc provenance traversal (`GraphifyIndex` in [`cpp/include/omnia/graph/graphify_index.hpp`](cpp/include/omnia/graph/graphify_index.hpp): `EXTRACTED` / `INFERRED` / `AMBIGUOUS`) before whole-repo grep dumps.

Give every worker an explicit contract naming inputs, strictly disjoint owned output paths (`disjoint_paths`), forbidden paths, acceptance checks, and stop conditions. **Serialize Git mutations and shared build-directory CMake/Ninja invocations** so concurrent linker/QA jobs never contend on output binaries or Win32 desktop focus. Treat agent reports as inputs to independent verification rather than automatic completion receipts.
