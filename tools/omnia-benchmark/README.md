# Harness Benchmark Suite (10-Axis Coding Agent Evaluation)

Zero-Docker, Windows-native, publication-grade 10-axis evaluation suite comparing coding agent harnesses (`goose`, `omp`, `omp-rpc`, `omp-omni`) across foundation models on `htmustc.id.vn`.

## Directory Layout

- `METHODOLOGY.md` — 10-axis benchmark design, industry benchmark provenance (AA Intelligence Index v5, SWE-bench Verified, Terminal-Bench 4.1, SWE-Atlas, LiveCodeBench, BFCL v4, Aider Polyglot), token normalization, and scoring formulas.
- `omp_profile/models.yml` — All 20 text/coding models from `https://htmustc.id.vn/v1/models` configured for OMP (`PI_CODING_AGENT_DIR`).
- `suite/tasks/<task_id>/` — 17 self-contained deterministic tasks across Axes 1–7 (`task.json`, `prompt.md`, `workspace/`, optional `setup.py`, hidden `verify.py`).
- `suite/manifest.json` — Validated task manifest generated by `validate_suite.py`.
- `proc_monitor.py` — Pure stdlib Win32 `ctypes` process-tree RSS, private commit, and CPU sampler.
- `runner.py` — Isolated per-task benchmark executor capturing exact streaming telemetry, normalized tokens, live RSS/CPU, and hidden verifier scores into `results/raw/<phase>/<harness>/<model>/<task_id>.json`.
- `scorer.py` — 10-axis Artificial Analysis-style aggregator generating `results/summary/<phase>/scoreboard.json` and `SCOREBOARD.md`.
- `validate_suite.py` — Automated integrity checker confirming all tasks fail cleanly on baseline workspaces (with 100% `PASS_TO_PASS` and 0% `FAIL_TO_PASS` on Axis 1 SWE-bench tasks).
- `bench_zero_ai_loopback.py` — Local release-binary timing, not model evaluation. The one-turn case checks the actual reply. The five-turn case requires successful read, search, edit and shell results and a marker created by the passing workspace test. Mock usage does not measure provider cost, cache hits or decode speed.

## Quick Commands

```powershell
# 1. Validate all 17 tasks & regenerate suite/manifest.json
python validate_suite.py

# 2. List all tasks
python runner.py --list-tasks

# 3. Dry-run 1 task across both Goose & OMP
python runner.py --phase dry_run --harnesses goose,omp --models gemini-3.8-flash --tasks swe_01_py_ledger

# 4. Run full Tier-1 pre-merge matrix (5 models x 2 harnesses x 17 tasks)
python runner.py --phase pre_merge --harnesses goose omp --models gemini-3.8-flash gemini-4-carbon claude-sonnet-5-5 claude-opus-5-5 gpt-6.2-sol --resume --retry-errors --concurrency 2

# 5. Run post-merge omp-omni evaluation (auto-detects scratch/omp-omni/target/release/omp-omni.exe --eval-rpc)
python runner.py --phase post_merge --harnesses omp-omni --models gemini-3.8-flash gemini-4-carbon claude-sonnet-5-5 claude-opus-5-5 gpt-6.2-sol --resume --retry-errors

# 6. Compute 10-axis scores & Markdown/JSON scoreboards
python scorer.py --phase pre_merge
python scorer.py   # all phases combined
```
