## 1. Executive Summary & Top 5 Discoveries

## 6. Reusable Patterns for `agy` / `agy-fast`

The following verified, non-bypass architectural patterns from `Google Drive Downloader` transfer directly to `agy` and `agy-fast` automation, CDP browsing, and file-transfer runtimes:

1. **Zero-Getter Console Lag Firewall (`extension/inject_main.js:189-250`, `src/stealthAndHooks.js:269-330`)**:
   - *Problem*: Many sites deploy DevTools-detection/freeze traps (`console.log(Object.defineProperty({}, 'id', { get() { debugger; } }))`) that hang headless Chromium/CDP agents or blow up log buffers.
   - *Pattern*: Wrap `console.{log,info,warn,debug,error,table,dir}` using `Object.getOwnPropertyDescriptor` inspection *without* invoking property getters, replacing getter-backed/deeply nested objects with inert tag summaries (`[Blocked Getter]`) and rate-limiting burst logging. Apply identically in `agy` CDP preload scripts.
2. **Closed-Shadow-DOM Boundary Guard (`extension/inject_main.js`, `src/stealthAndHooks.js`)**:
   - *Pattern*: Never indiscriminately hook every `attachShadow({ mode: 'closed' })` globally — `Google Drive Downloader` explicitly exempts built-in / CAPTCHA / anti-bot frame hosts (`turnstile`, `recaptcha`, `hcaptcha`, `altcha`) so automated DOM inspection never breaks or alters security-challenge frames. Adopt this exact allowlist/exclusion discipline in `agy-fast` accessibility tree walkers.
3. **CDN Signed-URL Raw `&`-Segment Preserving Sanitizer (`src/privacyShield.js` -> `Omnia` `privacy.rs`)**:
   - *Problem*: Naive `new URLSearchParams()` parsing re-encodes percent sequences (`%2F`, `%2B`, `+`), immediately invalidating AWS SigV4, CloudFront, GCS, and Akamai HMAC signatures.
   - *Pattern*: Split raw `url.split('#')[0].split('?')`, iterate raw `&`-delimited segments, decode ONLY the parameter *name* to check tracking-param blocklists (`utm_*`, `fbclid`, `gclid`, `__hstc`, etc.), and re-join kept segments byte-for-byte without re-encoding values. Critical for `agy` web-fetch & media cache layers.
4. **Manual Visible Handoff State Machine (`src/omni_drive_pro/visibleHandoffManager.js`, `Omnia` `handoff.rs`)**:
   - *Pattern*: Encode `EXECUTION_MODE_MANUAL_VISIBLE_BROWSER_ONLY` + `AUTO_SOLVE_PERMITTED = false` as an explicit non-retryable FSM (`Pending -> OpenedInVisibleBrowser -> Resolved | Cancelled | Expired`, with TTL clamping & single-flight domain lock). Whenever `agy` hits `401`/`403`/CAPTCHA/`429` sorry gates, short-circuit retries immediately and emit a resumable handoff ticket rather than burning retry budgets.
5. **Dual-Journal + Strong-Only Validator Resume (`src/omni_drive_pro/resumeJournal.js`, `hyperDownloader.js`, `Omnia` `journal.rs`)**:
   - *Pattern*: Combine a small atomic JSON control header (`.part.meta` enforcing **strong** `ETag` — refusing `W/"..."` and absent validators — plus `If-Range` fallback detection) with an append-only CRC32-framed binary log (`.omnf`, truncating any partial/corrupt trailing record on crash recovery). Directly reusable in `agy` large-artifact sync & `run-workflow` checkpoint logs.
6. **`CoalescedDiskWriter` + Bounded Dynamic Work-Stealing (`src/idm_core/idmDiskPreallocator.js`, `src/hyperDownloader.js:1411`, `Omnia` `chunker.rs`)**:
   - *Pattern*: Preallocate target file size up front, keep concurrent worker chunks buffered in `512 KiB–1 MiB` user-space slabs before `pwrite`/`seek_write`, steal the **midpoint** of the active worker with the largest remaining byte span above `minSplitBytes` (`256–512 KiB`), and always clamp `writeLen = min(buf.len(), chunk.end - chunk.offset + 1)` under lock before flushing so racing stealer + victim never overwrite adjacent ranges.
7. **`CombinatorialPoolDesign` Fault Localization + 3-Gram Jaccard Schema Drift (`src/omni_drive_pro/schemaDriftAndConformance.js`)**:
   - *Pattern*: Use `3`-gram SHA-256 multiset Jaccard similarity (`threshold >= 0.65`) to detect HTML/API template drift automatically in scraping agents (`agy`), and use combinatorial binary-pool test matrix attribution (`attributePoolCauses` / `confirmPoolCauses`) to isolate flaky/broken tools, plugins, or MCP endpoints in $O(\log N)$ runs instead of serial $O(N)$ bisection.
8. **Chrome TLS Cipher Ordering + Cross-Origin Redirect Header Stripping (`src/hyperDownloader.js`, `src/omni_drive_pro/scopedCookieJar.js`)**:
   - *Pattern*: Pair `CHROME_CIPHERS` ordering for public CDN TLS parity with a **manual 10-hop redirect loop** that checks SSRF IP/loopback/DNS-rebind bounds at every hop and **strips `Authorization`, `Cookie`, `Proxy-Authorization` whenever `(scheme, host, port)` changes**.
9. **ReDoS Static Validator + Okapi BM25 Tool/Provider Ranking (`src/omni_drive_pro/providerRegistry.js`)**:
   - *Pattern*: When admitting user/extension-contributed URL or skill regex patterns in `agy`, run a lightweight static parenthesis/quantifier nesting checker (`isSafeProviderRegex` / `has_redos_hazard`) before compilation, and rank candidate handlers with parameter-free/lightweight Okapi BM25 rather than raw substring matching.
10. **Bounded-Memory Wire Codecs & Anti-Prototype-Pollution Cloner (`src/omni_drive_pro/captureBundleStore.js`)**:
    - *Pattern*: Enforce `MAX_INFLATE_BYTES` on decompression (`inflateBounded`), `MAX_WIRE_JSON_DEPTH`, strict Base64 alphabet/padding validation (`decodeBase64Strict`), and recursive `__proto__` / `constructor` / `prototype` stripping (`stripDangerousKeysDeep`) whenever ingesting untrusted browser extension payloads or HAR/CDP capture bundles.
