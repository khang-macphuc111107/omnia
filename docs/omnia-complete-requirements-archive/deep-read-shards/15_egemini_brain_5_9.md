## 3. Reusable Architectural Insights, Bugs & Anti-Patterns Catalog

1. **OpenAI `/v1/responses` Namespace + `functions` Pseudo-Namespace Trap (`523958e9`, `8851cf65`, `6640e502`)**:
   - Codex `0.167.0` requires explicit `"namespace"` on non-root `function_call` items (`router.rs:365`).
   - With `use_responses_lite: true`, Codex moves tools into `input[].additional_tools` and wraps root tools inside `{"type":"namespace","name":"functions"}` — blindly restoring `namespace: "functions"` crashes root tools!
   - SSE chunking can split mid-frame or mid-UTF-8 character: reverse proxies MUST buffer via `StringDecoder` + `\r?\n\r?\n` frames, use zero-alloc byte gates (`!bytes.Contains("namespace")`/`"function_call"`), skip JSON Schema subtrees when scanning tool definitions, and ignore cross-namespace collisions (`ambiguous` set).
2. **Windows Process Creation & Path/ACL Traps (`6640e502`, `5c512245`, `8f5f6107`, `98f3c883`)**:
   - `Command::new("npx")` fails on Windows (`WinError 2`) because npm shims are `npx.cmd`.
   - Never recursively traverse `0x400` (`FILE_ATTRIBUTE_REPARSE_POINT`) directory junctions (`~20,198` pnpm links); check resolved containment before moves; audit stale-SID protected DACLs (`WinError 5`) instead of retrying unprivileged moves.
