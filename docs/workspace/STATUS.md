# Status entrypoint

Read [CHECKPOINT.md](CHECKPOINT.md) for the latest inspected state and
[GOAL.md](GOAL.md) for authoritative tasks and next actions.
[DOD.md](DOD.md) defines acceptance and final audit gates.

This entrypoint deliberately carries no duplicated status counters. The root
now tracks actual native/compatibility source. Clean root Git status still
does not prove physical cleanup, child-source reconciliation or product
completion. Historical counters require their named receipt and snapshot.
